Репозиторий картов
==================

``CartRepository`` создаёт, обновляет и удаляет карты и модели. Методы создания
возвращают ID, а обновление и удаление — ``False``, если запись отсутствует.
Операции выполняются в транзакции вызывающего кода.

При ссылке на отсутствующую модель репозиторий поднимает
``CartModelNotFoundError``. Удаление карта, связанного с заездом, даёт
``CartInUseError``, удаление модели с картами — ``CartModelInUseError``.
