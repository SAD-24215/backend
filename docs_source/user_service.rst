Сервис пользователей
====================

``UserService`` хеширует пароли при регистрации и создании сотрудников,
проверяет учётные данные при входе и получает текущую роль через репозиторий.
Успешная проверка учётных данных возвращает ``UserIdentity``, который используется
для выдачи токенов в API.
