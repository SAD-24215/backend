API картинг-центра
==================

Данные центра
--------------

* ``GET /api/v1/info`` возвращает адрес, правила и список моделей в ``price_list``.
* ``PUT /api/v1/info`` принимает ``address`` и ``rules`` и возвращает обновлённые
  данные вместе с прайс-листом.

Оба маршрута возвращают ``200`` при успехе и ``404``, если запись о центре отсутствует.
В каждой позиции прайс-листа есть ``cart_model_id``, ``name``, ``description``,
``price``, ``photo_path`` и ``cart_count``. Счётчик включает все карты модели,
в том числе недоступные. Для фото используется ``/images/test_image.jpg``.

Карты и модели
--------------

Все маршруты этого раздела требуют ``Authorization: Bearer <access_token>``
и роль ``admin``. Без действительного токена ответ ``401``, без роли
администратора — ``403``.

* ``POST /api/v1/carts`` принимает ``cart_model_id`` и необязательное поле
  ``is_available`` (по умолчанию ``true``).
* ``PUT /api/v1/carts`` обновляет модель и доступность карта. В теле запроса
  обязательны ``id``, ``cart_model_id`` и ``is_available``.
* ``DELETE /api/v1/carts?cart_id=7`` удаляет карт по ID. Для карта, связанного
  с заездом, ответ ``409``.
* ``POST /api/v1/cart_models`` принимает ``name``, ``description`` и ``price``.
* ``PUT /api/v1/cart_models`` принимает те же поля и обязательный ``id`` модели
  в теле запроса.
* ``DELETE /api/v1/cart_models?cart_model_id=2`` удаляет модель по ID. Если
  к ней привязаны карты, ответ ``409``.

После создания API возвращает ``201`` и адрес созданного ресурса в заголовке
``Location``, после обновления — ``200``. Тело этих ответов содержит данные
центра с обновлённым прайс-листом. Успешное удаление возвращает ``204`` без тела.
Если нужный карт, модель или запись о центре отсутствуют, API возвращает ``404``.
