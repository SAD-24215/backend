Репозиторий картинг-центра
==========================

``InfoRepository`` читает и обновляет запись центра с наименьшим ID. Для
прайс-листа он возвращает по одной записи ``CartModelInfo`` на модель и
подсчитывает все её карты, включая недоступные. Для модели без картов счётчик
равен нулю.
